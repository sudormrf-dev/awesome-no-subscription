# Productivity

Notes, office suites, task management, knowledge bases, email clients, and personal organization tools.

---

### [Obsidian](https://obsidian.md/)
:free: Free for personal use | Windows, macOS, Linux, iOS, Android
**Replaces:** Notion ($10/mo), Roam Research ($15/mo)
Markdown-based knowledge management with bidirectional linking, graph view, and a massive plugin ecosystem. All data stored as local plain-text files you own. Optional paid sync ($48/yr) and publish services, but the core app is fully functional without them.

### [Logseq](https://logseq.com/)
:unlock: Open source (free) | Windows, macOS, Linux, iOS, Android
**Replaces:** Notion ($10/mo), Roam Research ($15/mo)
Outliner-based knowledge management with bidirectional links, block references, and graph visualization. Local-first with data stored in Markdown and Org-mode files. Built-in task management and journaling.

### [LibreOffice](https://www.libreoffice.org/)
:unlock: Open source (free) | Windows, macOS, Linux
**Replaces:** Microsoft 365 ($7/mo per user)
Full office suite with Writer (documents), Calc (spreadsheets), Impress (presentations), Draw (diagrams), Base (databases), and Math (formulas). Reads and writes Microsoft Office formats. Mature, stable, and widely used.

### [Thunderbird](https://www.thunderbird.net/)
:unlock: Open source (free) | Windows, macOS, Linux
**Replaces:** Microsoft Outlook ($7/mo with Microsoft 365)
Feature-rich email client with calendar, contacts, and task management. Supports IMAP, POP3, and Exchange via add-ons. Built-in RSS reader and extensive add-on ecosystem. Backed by Mozilla.

### [KeePassXC](https://keepassxc.org/)
:unlock: Open source (free) | Windows, macOS, Linux
**Replaces:** 1Password ($3/mo), LastPass ($3/mo)
Offline password manager with browser integration, TOTP support, SSH agent, and auto-type. Database stored locally in encrypted KDBX format. Sync via any cloud service by placing the database file in a synced folder.

### [Cryptomator](https://cryptomator.org/)
:unlock: Open source (free on desktop) | Windows, macOS, Linux, iOS, Android
**Replaces:** Boxcryptor (discontinued), cloud encryption subscriptions
Client-side encryption for cloud storage. Creates encrypted vaults in Dropbox, Google Drive, OneDrive, or any folder. Transparent encryption -- files appear as a virtual drive. Mobile apps are paid one-time purchases.

### [Standard Notes](https://standardnotes.com/)
:free: Free tier (extended $90/yr optional) | Windows, macOS, Linux, iOS, Android
**Replaces:** Evernote ($15/mo)
Encrypted note-taking with a focus on longevity and privacy. The free tier includes unlimited notes with end-to-end encryption. Extended subscription adds themes, editors, and cloud features but is not required for core use.

### [Joplin](https://joplinapp.org/)
:unlock: Open source (free) | Windows, macOS, Linux, iOS, Android
**Replaces:** Evernote ($15/mo)
Note-taking and to-do application with Markdown support, end-to-end encryption, and synchronization via Nextcloud, Dropbox, OneDrive, or WebDAV. Supports web clipping, tags, notebooks, and full-text search.

### [Vikunja](https://vikunja.io/)
:unlock: Open source (free, self-hosted) | Web, Windows, macOS, Linux
**Replaces:** Asana ($11/mo per user), Todoist ($5/mo)
Open-source task management and project planning with Kanban boards, Gantt charts, calendars, and team collaboration. Self-hosted with a clean web interface. Supports CalDAV for calendar integration.

### [Todoist](https://todoist.com/)
:free: Free tier | Web, Windows, macOS, Linux, iOS, Android
**Replaces:** Asana ($11/mo per user) for personal task management
Task management with natural language input, projects, labels, filters, and recurring tasks. The free tier supports up to 5 active projects and basic features. Clean interface available on every platform.

### [Calibre](https://calibre-ebook.com/)
:unlock: Open source (free) | Windows, macOS, Linux
**Replaces:** Kindle manager, paid ebook management tools
Comprehensive ebook management: organize, convert between formats, edit metadata, sync to devices, and read. Built-in content server for remote access. Supports virtually every ebook format.

### [Zotero](https://www.zotero.org/)
:unlock: Open source (free) | Windows, macOS, Linux
**Replaces:** Mendeley (Elsevier-owned), EndNote ($275/yr)
Reference manager for academic research. Collects, organizes, cites, and shares research sources. Browser integration for one-click saving. Built-in PDF reader with annotation. 300MB free cloud storage for syncing.

### [Trilium Notes](https://github.com/zadam/trilium)
:unlock: Open source (free, self-hosted) | Windows, macOS, Linux
**Replaces:** Notion ($10/mo) for personal knowledge management
Hierarchical note-taking application with rich editing, relation maps, scripting, and full-text search. Self-hosted with optional sync server. Supports note cloning, attributes, and a powerful scripting API.

### [Orca One](https://orcaone.com/)
:moneybag: $29.99 one-time launch price ($59.99 regular) | macOS 15+ (Apple silicon)
**Replaces:** Wispr Flow Pro ($15/mo)
Dictate into any Mac app and capture meeting transcripts with on-device speech recognition. A one-time license includes future updates and does not require a subscription.
